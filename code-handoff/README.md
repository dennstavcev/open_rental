# SoftRent — перенос концепции дизайна в код

Concept-прототип: `OpenRent.dc.html` (в корне проекта) — интерактивный референс UX/UI.

Эти файлы — **drop-in замены** для твоего Next.js фронтенда. Пути внутри
`code-handoff/frontend/` повторяют структуру `apartment rental/frontend/`.
Скопируй с заменой и запусти `npm run dev` — увидишь на localhost сразу,
без изменений бэкенда.

## Что менять (скопировать поверх)

| Файл | Что несёт |
|------|-----------|
| `app/layout.tsx` | `<title>` → **SoftRent**, описание с новым слоганом |
| `app/login/page.tsx` | Бренд **SOFTRENT** + слоган «Всё нужное — в одном окне.» |
| `app/register/page.tsx` | Бренд **SOFTRENT** + слоган; блок про роль (роль по объекту, не при входе) сохранён |
| `components/TopBar.tsx` | Бренд **SOFTRENT** в сайдбаре и мобильной шапке |

Все токены дизайна (цвета, типографика, отступы, frosted-glass, фиолетовый
акцент) уже лежат в твоём `app/globals.css` — правки визуала не требуют CSS.
Используется существующий класс `.auth-brand`.

## Что ещё осталось в коде со старым именем (по желанию)

- `lib/api.ts` — ключи localStorage `openrent.accessToken` / `openrent.refreshToken`.
  Можно переименовать в `softrent.*`, но это разлогинит текущие сессии — меняй
  осознанно (лучше вместе с бэкендом).
- `package.json` / `package-lock.json` — `"name": "openrent-frontend"`. Косметика,
  на UI не влияет.

## Дальнейший перенос концепции (по запросу)

Прототип показывает более глубокую перестройку навигации:
- Лента **«Требует действия»** на «Сегодня» — выносит наверх единственный
  следующий шаг (подтвердить оплату, согласовать заявку, подать показания,
  подписать договор).
- **Хаб аренды** — всё про один договор на вкладках (Обзор/Счета/Показания/
  Чат/Заявки/Документы), вместо разбросанных страниц.

Это уже затрагивает `app/dashboard/page.tsx` и маршруты `app/leases/[id]/*`,
завязано на реальные API — переносится постранично. Скажи, с какого экрана
начать, и подготовлю такие же drop-in файлы.
