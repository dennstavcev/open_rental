# Дизайн-система

> Статус: черновик-заготовка. Заводится и ведётся `designer`
> (`.claude/agents/designer.md`) на основе Figma-референса и решений
> ниже. Пока содержит только то, что уже зафиксировано в
> `docs/PRODUCT_QUESTIONS.md` (15.1–15.3) — остальное дизайнер
> разворачивает по мере перевода экранов из `docs/MVP_SCOPE.md` в спеки.

## Что уже решено

- **Референс (приоритетный) — Claude Design**, проект предоставлен CEO
  2026-07-22: https://claude.ai/design/p/9d23e4c8-1e7a-44a7-862a-3d3e5fb89e0e —
  импортируется `designer`-агентом через MCP `claude_design`
  (`https://api.anthropic.com/v1/design/mcp`, авторизация — `/design-login`
  в CLI). Как и любой референс — отправная точка, не буквальная
  спецификация; расхождения с `docs/USER_FLOWS.md`/`docs/MVP_SCOPE.md`
  решаются в пользу документации, уточняются у CEO.
- **Референс (более ранний) — Figma**, предоставлен CEO 2026-07-21
  (https://www.figma.com/design/sYKpsyXDvmj0cDWTKC5bTF/OpenPay), см.
  `README.md`. Использовался до появления Claude Design проекта —
  актуальность и приоритет между ними уточняет `designer` у CEO, если
  экраны расходятся.
- **Тон** — тёплый, спокойный, премиальный лайфстайл-тон: приглушённая
  земляная палитра, мягкий свет, минимализм. Не формально-юридический
  и не подчёркнуто игривый.
- **Акцент** — фиолетовый градиент на ключевых CTA.
- **Платформа** — адаптивный веб, мобильный браузер приоритетнее
  десктопа (~90% использования с телефона, см. `docs/MVP_SCOPE.md`).
- **Название продукта** — рабочее, OPENRENT (предварительное).

## Что предстоит собрать (зона `designer`)

- Полная цветовая палитра (не только акцент), типографика, сетка/отступы.
- Библиотека состояний компонентов: обычное, hover, ошибка, загрузка,
  пустое состояние — для каждого переиспользуемого элемента (карточка
  объекта, строка счёта, статус заявки и т.п.).
- Подетальные спеки экранов по каждому модулю из `docs/MVP_SCOPE.md`,
  начиная с онбординга (`docs/USER_FLOWS.md`, 1.1–1.2).
