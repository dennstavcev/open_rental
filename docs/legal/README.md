# Юридические тексты

Единственный экземпляр текста политики обработки персональных данных,
даты обновления и вычисляемой версии находится в
`backend/src/legal/privacy-policy.const.ts`. Frontend получает все три
значения через публичный `GET /legal/privacy-policy` и не хранит своей
копии текста или версии.

Исходники `.docx` намеренно лежат вне репозитория `open_rental`: они
подготовлены для другого сервиса (`flashformat.ru`) и не проверены юристом
для SoftRent. Переносить их текст в продукт без отдельной юридической
редакции нельзя.

## Как опубликовать финальную редакцию

1. Заменить `PRIVACY_POLICY_HTML` на согласованный юридический текст.
2. Поднять ручную дату-метку в функции, формирующей
   `PRIVACY_POLICY_VERSION`, и убрать суффикс `-draft`.
3. Обновить `PRIVACY_POLICY_UPDATED_AT` фактической датой редакции.
4. Запустить backend-тесты, typecheck и сборку, затем frontend typecheck и
   сборку.

Короткий SHA-256-хеш HTML входит в `PRIVACY_POLICY_VERSION`. Поэтому
изменить текст и сохранить прежнюю версию технически невозможно: хеш
поменяется автоматически, а формы запросят согласие заново.
